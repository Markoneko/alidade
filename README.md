# Alidade

*Viser, apprendre, faire le point · Aim, learn, take a fix*

Les ressources pédagogiques interactives de Marc Poupée : enseignements à Géodata Paris et dans le master FIRS, formations associatives au CNIF, projets ludo-éducatifs.

Le jour, la page d'entrée se lit comme un portulan ; la nuit, les îles deviennent des constellations.
